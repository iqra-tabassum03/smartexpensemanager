# 💰 Smart Expense Manager

> A modern Android app to **track income, expenses, and manage your financial health** with ease.  
> Built with **Kotlin + Material Design 3**, it empowers users to take control of their financial journey.

---

## ✨ Features

- 📊 **Dashboard Overview**
  - Current balance, total income, and expenses at a glance.
  - Recent transactions list with categories and timestamps.

- 🧾 **Transaction Management**
  - Add, edit, and delete transactions.
  - Categorize expenses (Shopping, Fees, Gifts, etc.).
  - Set reminders for recurring expenses.

- 📈 **Reports & Insights**
  - Interactive charts (PieChart, BarChart) for spending breakdown.
  - Filter by **Weekly, Monthly, Yearly** using ChipGroup filters.
  - Key insights card highlighting spending patterns.

- 👤 **Profile & Settings**
  - Edit profile details.
  - Change password.
  - Toggle dark mode.
  - Manage notifications and reminder times.
  - Privacy policy, help & support, feedback, and logout.

- 🎨 **Modern UI/UX**
  - Material Design 3 components (CardView, ChipGroup, FAB).
  - Theme-aware colors for light/dark mode.
  - Accessibility support with proper `contentDescription`.

---

## 🛠️ Tech Stack

- **Language:** Kotlin  
- **Architecture:** MVVM (ViewModel + Repository + LiveData)  
- **UI:** Material Design 3, CoordinatorLayout, FAB, Snackbar  
- **Database:** Room (for transactions persistence)  
- **Charts:** MPAndroidChart library  
- **Navigation:** Jetpack Navigation Component
